# YFCDN Roadmap

## v0.1, included in this starter

- Control plane with JSON persistence.
- Original web console.
- Tenants, operators, nodes, domains, plans and API keys.
- Edge agent that pulls config and reloads Nginx.

## v0.2

- PostgreSQL storage adapter.
- Role based access control.
- Domain ownership verification by TXT record.
- Traffic accounting by parsing Nginx logs.
- Better WAF presets and per-domain rules.
- API pagination, filtering and audit exports.

## v0.3

- ACME certificate automation.
- Tenant portal and operator portal separation.
- Billing records, top-up credits and package quota enforcement.
- DNS provider integration.
- Cache purge API.
- Prometheus metrics exporter.

## v1.0

- Multi-control-plane HA.
- Multi-region routing policies.
- Clustered edge node groups.
- Abuse report workflow and compliance tooling.
- Backup/restore and migration tools.


## v0.1.2

- 简体中文默认语言和中英文切换。
- 前端事件代理修复菜单/按钮点击问题。
- 一键节点安装脚本。
- 主控和节点同机部署模式。
